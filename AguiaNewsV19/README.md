# Pombo News — Android 1.0.21

Atualização da identidade e experiência do app:
- Marca Pombo News com logo SVG adaptativa para modo claro/escuro.
- Tema claro/escuro refinado e preferência persistente.
- Modo sem política persistente.
- Últimas notícias com atualização manual e automática.
- Alertas de notícias urgentes com notificações Android quando ativados pelo usuário.
- Tela inicial com acabamento visual e hierarquia aprimorados.

Observação: os alertas urgentes são disparados quando o app está aberto e executa uma atualização do feed; a permissão de notificações é solicitada somente quando o usuário ativa o recurso.


### Ícone do aplicativo
O ícone oficial do Pombo News foi atualizado para usar o pombo com globo em fundo azul, sem a margem quadrada anterior.
